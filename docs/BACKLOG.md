## 付録: 技術的な実装メモ

### サブスクリプション実装（完了）
```typescript
// 追加されたDBテーブル
- el_subscription_plans (id, name, slug, description, price_monthly, price_yearly, ...)
- el_user_subscriptions (id, user_id, plan_id, stripe_subscription_id, status, ...)
- el_subscription_payments (id, subscription_id, amount, status, ...)

// 追加されたAPIエンドポイント
- GET /v1/subscriptions/plans - プラン一覧
- GET /v1/subscriptions/my-subscription - 現在のサブスクリプション
- POST /v1/subscriptions/subscribe - 新規購読
- POST /v1/subscriptions/cancel - キャンセル
- POST /v1/subscriptions/resume - 再開
- POST /v1/subscriptions/change-plan - プラン変更
- GET /v1/subscriptions/payments - 支払い履歴
- GET /v1/subscriptions/check-access - アクセス確認

// フロントエンド
- /pricing - 料金ページ
- /dashboard/subscription - サブスクリプション管理ページ
```
