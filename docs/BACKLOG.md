## 付録: 技術的な実装メモ

### サブスクリプション実装方針
```typescript
// 必要なDB追加テーブル
- el_subscription_plans (id, name, price_monthly, price_yearly, features)
- el_user_subscriptions (id, user_id, plan_id, stripe_subscription_id, status, ...)

// Stripe連携
- Stripe Subscription API
- Webhook: invoice.paid, customer.subscription.updated, customer.subscription.deleted
```

### 字幕対応実装方針
```typescript
// DB追加
- el_video_subtitles (id, video_id, language, srt_url, is_default)

// API追加
- POST /v1/videos/:id/subtitles - 字幕アップロード
- GET /v1/videos/:id/subtitles - 字幕一覧取得
- DELETE /v1/videos/:id/subtitles/:subtitleId - 字幕削除

// フロントエンド
- VideoPlayerコンポーネントにtrack要素追加
- 字幕ON/OFFトグル
```

### 講師審査申請フロー
```typescript
// 現状のコースステータス
- draft: 下書き
- pending_review: 審査待ち（現状存在するが申請UIなし）
- published: 公開
- rejected: 却下

// 必要なUI
- 講師ダッシュボード: 「審査に提出」ボタン
- 審査ステータス表示: ステータスバッジ
- 却下時: 理由表示 + 再申請機能
```
